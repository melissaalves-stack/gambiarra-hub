O **Gambiarra Hub** é o maior (e único) e-commerce satírico do mundo focado na aquisição de débitos técnicos, soluções temporárias definitivas e más práticas de programação. 

Feito para desenvolvedores seniores cansados, juniores em pânico e gerentes de projeto que acreditam em milagres.

🌐 **Acesse a aplicação em produção:** [gambiarra-hub.vercel.app](https://gambiarra-hub.vercel.app/)

---

## 📦 O que você encontra no nosso Catálogo?

* 👻 **JavaScript Fantasma™**: Aquele arquivo `script.js` de 2019 que ninguém sabe o que faz, mas se apagar, o menu da página some.
* 💪 **CSS Força Bruta™**: A arte milenar de resolver qualquer conflito de layout colocando `!important` em absolutamente todas as linhas.
* 🔀 **O IF Infinito™**: Uma estrutura de decisão encadeada de 450 linhas que cobre cenários reais, hipotéticos e espirituais.
* 🎲 **Simulador de Risco**: Uma ferramenta preditiva de engenharia caótica para calcular as suas chances exatas de ser demitido ao dar um `git push --force` na branch `main` numa sexta-feira às 17h54.
* 🛒 **[ CART_TERMINAL ]**: Um carrinho de compras cyberpunk totalmente funcional (para fins de simulação de falência).

## 💻 Demonstrações Interativas (Features)

Diferente de e-commerces normais, aqui o cliente testa o estrago antes de comprar:

1. **O Inspetor Paranormal:** Permite revelar ou ocultar o código do *JS Fantasma*.
2. **O Destruidor de Layouts:** Injeta conflitos de especificidade em tempo real no *CSS Força Bruta* para você ver o site derretendo ao vivo.
3. **O Contador de Desespero:** Adicione `else if`s infinitamente na nossa ferramenta de lógica até o navegador pedir socorro.

## 🧠 O Aprendizado Oculto (O Lado Sério da Gambiarra)

À primeira vista, o **Gambiarra Hub** parece apenas um antro de piadas internas para programadores exaustos. Mas, na verdade, este projeto foi um excelente campo de treino para dominar o desenvolvimento web moderno. 

Afinal, **para quebrar as regras com elegância e de propósito, é preciso compreendê-las profundamente.**

Eis as competências reais em HTML, CSS e JavaScript que foram consolidadas no desenvolvimento deste projeto:

### 📑 HTML5: Arquitetura Estrutural
* **Semântica de E-commerce:** Organização rigorosa de uma aplicação de várias páginas usando tags semânticas reais (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), garantindo que o layout seja robusto.
* **Formulários Avançados e Validação:** O *Simulador de Risco* exigiu o uso de múltiplos tipos de input (radios, checkboxes, selects) estruturados de forma limpa para manipulação de dados em massa.
* **Componentes Dinâmicos:** Criação e estruturação de estruturas ocultas na árvore do DOM, como o modal nativo do `[ CART_TERMINAL ]`.

### 🎨 CSS3: Engenharia do Caos Controlado
* **Domínio da Cascata e Especificidade:** Para criar a demonstração do *CSS Força Bruta*, foi necessário estudar exatamente como o motor do browser processa herança e especificidade para simular os conflitos e criar uma "restauração" via `!important`.
* **Filtros e Distorções Gráficas:** Implementação de efeitos visuais dinâmicos através de propriedades avançadas como `filter: blur()`, `hue-rotate()`, `skewX()` e `transform: rotate()`.
* **Posicionamento Absoluto:** Desenvolvimento da lógica de layout do botão de suporte fujão (na página Quem Somos), exigindo um entendimento perfeito das coordenadas de eixos e da relação entre `position: relative` e `absolute`.

### ⚡ JavaScript Pure (Vanilla JS): O Motor da Lógica
* **Manipulação Assíncrona do DOM:** Utilização intensiva de `addEventListener` para capturar interações do utilizador e injetar logs dinâmicos que simulam terminais reais a correr em tempo real.
* **Gestão de Estado (State Management):** Criação de um carrinho de compras funcional que mapeia arrays de objetos, calcula totais dinamicamente, atualiza badges na interface e mantém a consistência dos dados.
* **Controlo de Tempo e Loops:** Uso estratégico de `setTimeout` e `setInterval` para criar a ilusão de processamento ("código a pensar") e loops que geram o encadeamento visual de blocos no *IF Infinito*.
